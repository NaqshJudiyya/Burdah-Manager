هذه القيم تُستخدم كافتراضات للصفحات التي لا تملك إعداد SEO خاصًا. لن نضع كلمات مفتاحية غير موجودة في المحتوى تلقائيًا.

الفهرسة والزحف

حالة التخزين

المدير يعمل محليًا فقط. النسخة الاحتياطية JSON تحفظ البيانات، أما التصدير النهائي فينشئ حزمة Static تشمل HTML/CSS/JS وassets وSEO files.

النسخ الاحتياطية التلقائية

تُحفظ آخر 3 نسخ من بياناتك تلقائيًا داخل المتصفح قبل كل تعديل جديد، لتتمكن من الرجوع خطوة للخلف عند الحاجة.

ما الذي سيُنشأ عند التصدير؟

  • Title وMeta Description وCanonical.
  • Open Graph وTwitter Cards.
  • Structured Data بصيغة JSON-LD.
  • sitemap.xml وrobots.txt.
  • 404.html وملف _headers لـ Cloudflare Pages.
  • صفحات منفصلة للمؤلفين والمصادر والأبيات الرئيسية.

تصدير الموقع

سيتم إنشاء نسخة Static منظمة من الموقع مع بقاء مدير المحتوى منفصلًا. النسخة النهائية لا تحتاج إلى قاعدة بيانات أو سيرفر ديناميكي.
